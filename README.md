# 🐻 Morzinho — moda infantil

Landing page da Morzinho, "roupinhas pra quem é todo amor".

- Página única, autossuficiente (`index.html`) — CSS, JS e as 11 fotos embutidas em base64.
- Sem build, sem dependências externas.

## Cloudflare Pages
1. Pages → **Create a project** → **Connect to Git** → repo `danielgonzagat/morzinho`.
2. Branch de produção: `main`. Build command: *(vazio)*. Output directory: `/`.
3. Deploy. O `index.html` é servido na raiz automaticamente.
